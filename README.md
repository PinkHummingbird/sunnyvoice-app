# sunnyvoice-app

SunnyVoice: Journal your Mood — the app's public website, served by GitHub Pages. No app source code lives here.

- `index.md` — the landing page
- `privacy.md` — privacy policy (`/privacy`), the App Store Privacy Policy URL target
- `terms.md` — terms of use (`/terms`), on top of Apple's standard EULA
- `support.md` — support page (`/support`), the App Store Support URL target

Drafted 2026-10-20 from the app repo's docs/HOW_IT_WORKS.md and PRODUCT_SPEC.md. When the app's data handling changes (for example the web companion launches), update `privacy.md` before the app ships the change.
